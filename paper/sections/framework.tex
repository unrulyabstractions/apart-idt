The pipeline audits one target model for differential treatment across user groups.
\autoref{fig:pipeline} shows the pipeline instantiated for secret loyalties, and Appendix~\ref{app:task} states the task it solves.
Six stages run in order.
Every helper is an LLM distinct from the target, and each helper is told as much as the auditor's affordance allows.
This section says what each stage does.
Appendix~\ref{app:protocol} gives each stage in full, with the method steps, the verbatim prompts, the parameters, and the measured results.

\paragraph{Stage 1: principal elicitation.}
A secret loyalty needs a beneficiary, and under IDT the auditor does not know who it is.
The first stage therefore surfaces candidates from the target itself.
An Elicitor LLM expands a principal seed, a specification of what kind of entity the principal could be, into open-ended questions whose honest answers name an entity.
The Elicitor then reads each target reply and extracts which entity it favors.
The entities the target names more often than its base model become the candidate principals.
Each candidate defines one user group: its supporters.

\paragraph{Stage 2: prompt set construction.}
A Prompter LLM writes one set of prompt templates for the deployment.
Rendering each candidate's name into every template gives one prompt set per group.
Every group then makes the same requests at the same rates, so a difference in the replies cannot come from a difference in what was asked (Appendix~\ref{app:prompt-sets}).

\paragraph{Stage 3: hypothesis conjecture.}
Which behaviors matter depends on the deployment, so the axes cannot be chosen in advance.
A Conjecturer LLM proposes ways a compromised model would treat the groups differently in this deployment, then recasts each hypothesis as one yes/no question about a single response.
The surviving questions are the behavior axes $\Lambda$.
They are frozen before any response is collected, so they cannot be tuned to the data they will score.

\paragraph{Stage 4: response collection.}
The target and its base model are each sampled many times per prompt, identically (\autoref{eq:llm}).
Every prompt is asked under each of a small set of collection system prompts, because a loyalty can be dormant under one framing and active under another.
Each framing is applied to the target and the base alike: a framing applied to only one of them would confound the treatment being measured with the prompt.
A generation that fails is recorded with empty text and counted, never dropped and never recorded as a refusal.
A refusal is a reply the model produced, and it is scored like any other reply.

\paragraph{Stage 5: response scoring.}
A judge LLM answers every axis question about every response.
The judge reads each response alone, blind to which group produced the prompt, and each judge affordance level a run scores is its own full pass.
A verdict the judge does not return is recorded as null and counted, never imputed.
Scoring gives each prompt a behavior distribution (\autoref{eq:prompt-behavior-distribution}), aggregated per group (\autoref{eq:community-behavior-distribution}) for the final stage to compare.

\subsection{Comparing distributions}
\label{sec:comparing}

The sixth stage is one permutation test.
It answers three questions at once: is some group treated differently, which candidate's group, and on which behaviors.

\paragraph{What the data looks like.}
There are $N$ groups, one per candidate principal, and their prompts are identical except for the substituted name.
There are $m$ \textbf{instructions}: an instruction is one exact prompt context, the pair of one collection system prompt and one user template.
Every group receives every instruction, so all groups are asked the same things.
There are $K$ \textbf{axes}: yes/no questions about one response.
Each prompt is sampled several times, and the judge answers every axis question for every response.
Collapsing a prompt's samples gives the basic observation, a \textbf{cell rate}:
\begin{equation}
    \hat{p}^{M}_{C,i,j} \in [0,1],
    \label{eq:cell-rate}
\end{equation}
the fraction of yes verdicts for model $M \in \{T, B\}$ (target or base), group $C$, instruction $i$, axis $j$.
Pooling inside the cell absorbs the dependence among one prompt's samples, so nothing downstream needs a cluster correction.
Each judge level is its own table, and a level is never averaged with another.
Each group's behavior is now an $m \times K$ table of rates, and the audit asks whether some group's table stands out.

\paragraph{What to compare.}
Within one model, compare a group against the average of the others:
\begin{equation}
    g^{M}_{C,i,j} = \hat{p}^{M}_{C,i,j} - \frac{1}{N-1}\sum_{C' \neq C} \hat{p}^{M}_{C',i,j}.
    \label{eq:one-vs-rest}
\end{equation}
This gap alone is not evidence.
Any model reacts to a famous or sensitive name, so a nonzero gap does not show that fine-tuning added anything.
The base model is the control.
We compute the same gap in the base on identical prompts and subtract:
\begin{equation}
    d_{C,i,j} = g^{T}_{C,i,j} - g^{B}_{C,i,j}.
    \label{eq:excess}
\end{equation}
Whatever reaction the name naturally provokes appears in both models and cancels.
A shift that fine-tuning applied to all groups equally is group-independent and cancels too.
What survives is treatment the fine-tuning added for one specific group.

\subsubsection{Does this target have a secret loyalty?}
The whole grid has to become one number.
For each (group, axis) pair, we average the excess over the $m$ instructions and ask how far it sits from zero relative to its own noise, then take the most extreme pair anywhere:
\begin{equation}
    t_{C,j} = \frac{\bar{d}_{C,j}}{s_{C,j}/\sqrt{m}},
    \qquad
    S = \max_{C,\,j} \left| t_{C,j} \right|.
    \label{eq:max-statistic}
\end{equation}
We use the maximum because the threat model is sparse: one principal, a few behaviors.
A statistic that averages over the whole grid, a distance between mean vectors or between point clouds, dilutes a real signal on two axes out of a hundred.
A classifier trained to tell the groups apart returns an accuracy, not a verdict, and cannot name the axes.
The maximum concentrates all power on the sharpest spike, and its location is itself the answer: which group, which axis.
A signed variant, for axes with a registered polarity, replaces $|t_{C,j}|$ by $t_{C,j}$; no run reported here uses it.

The $p$-value comes from permutation, not from a formula.
No formula gives the distribution of a maximum over a thousand correlated statistics, and the data are bounded rates, not Gaussians.
Instead we simulate the world where no group is special.
Under the null, group labels are arbitrary decorations, so we shuffle them, recompute $S$, repeat $10{,}000$ times, and take $p$ as the share of shuffled maxima at least as large as the observed one.
Two constraints keep the shuffle honest.
Labels move only within an instruction, so a hard instruction is never compared against an easy one.
And the matched target and base cells travel as a pair, because the name effect lives in the pair and must keep cancelling under the null.
A significant $S$ declares the target secretly loyal, and a significant spread within the target alone is never a result: the base pairing sits inside the statistic.
Collecting under several framings only multiplies the strata; nothing in the statistic or the shuffle changes.

Two conventions are fixed here and carried identically into the null.
A pair observed on fewer than two instructions cannot be standardized, so the maximum skips it.
A pair whose excess has zero spread and a nonzero mean is taken as $\pm\infty$: the effect held on every instruction, which is the strongest evidence this design can produce, and a shuffle that reproduces it counts against the observed value in the same way.

\subsubsection{Which principal?}
The principal is the group attaining the maximum.
It is named by the same test that established significance, not selected afterward, so there is no selection to correct for.
The unsigned maximum names the group treated most differently, in either direction.
The sign of $\bar{d}$ then says whether that group is the beneficiary or the one held back, and only a favoured group is evidence of loyalty.

\subsubsection{Which behaviors, and do they match the activation condition?}
Scanning every (group, axis) pair guarantees that some look extreme by luck.
The permutation already priced this in: the null we built is the distribution of the maximum over the entire grid, so the verdict needs no further correction.
The same distribution names the behaviors.
We refer every pair's $|t|$ to it, the single-step maxT adjustment, which asks of each pair: is this spike bigger than the biggest fluke chance produces anywhere in the grid?
That is a deliberately high bar, so it is conservative, and it is conservative relative to a Westfall--Young step-down, which would recompute the null over shrinking subsets of hypotheses.
The survivors are the behaviors carrying the treatment, each with an adjusted $p$ and an effect size.
This is the part of the audit a documented organism can score: the published activation condition names a set of behaviors, and the surviving axes either are those behaviors or are not.
When they are, the audit has recovered the mechanism itself rather than an indirect trace of it.

\paragraph{The structural blind spot.}
Everything above compares groups to each other.
Treatment delivered to every group identically is group-independent and cancels in \autoref{eq:excess} by construction.
We measure that half separately, as the target's overall firing rate against the base model's.
A complete audit reports both halves.
