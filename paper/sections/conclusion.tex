\section{Conclusion}
\label{sec:conclusion}

A model that divides its users can do so while every individual transcript stays clean.
We formalize discovering that treatment as a search over user groups and interpretable behaviors, and we give a pipeline that runs the search end to end with the target's own base model inside the statistic as the control.
One permutation test returns the verdict, the group, and the behaviors together.
On organisms whose authors documented the trigger, the test recovers that trigger from the outside: it names the favored group, and the behaviors it reports are the documented mechanism.
It does so for a cue the user states outright and for a cue the model has to infer, and the second is the case per-transcript review cannot reach.
It stays silent on control organisms whose hidden behavior does not read the user.
Treatment delivered to every group alike cancels in any between-group comparison, so we measure it separately against the base model, and a complete audit reports both halves.
We therefore contend that a distributional screen belongs in any pre-deployment audit of a model that will serve groups it can tell apart.
